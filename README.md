## 🛠️ 16 個真實落地專案主題庫（實務分析）

### 🏫 一、校園管理與行政專案
1. **TSCHOOL 空間借用系統**：Google Sheet + Apps Script 零成本架構，徹底解決教室借用撞期與紙本簽核痛點。
2. **TSCHOOL 學生自主學習歷程展示平台**：模組化作品櫥窗，支援影片、PDF、3D 模型與標籤檢索。
3. **TSCHOOL 招生宣傳互動心理測驗**：2 分鐘情境式是非測驗，自動產製個人化學習特質雷達圖與卡片。

### 🎯 二、自主學習任務專案
4. **故宮文化實境解謎任務生成器**：破除傳統參觀抄寫模式，將器物細節轉化為推理線索與密碼鎖。
5. **2026 臺灣科教展現場互動闖關系統**：開展當天即時完成的極限 Vibe Coding，順暢抗住數百人現場即時闖關。
6. **學習歷程指南互動目錄與前導教材**：將沉悶 PDF 轉化為四步曲互動地圖與 Checkbox 檢核清單。
7. **字音字形自主練字與手寫辨識平台**：大尺寸 Canvas 平滑指寫，拆解模組化 JSON 題庫告別遺忘痛點。

### 📚 三、課程教學與評量專案
8. **課堂互評回饋抽籤與即時接力工具**：大螢幕動態轉盤抽籤，結合組別防重複機制與發表倒數計時。
9. **兩日工作坊復盤與 SEL 五維度自評系統**：融入社會情緒學習指標，支援拍照上傳與雷達圖生成。
10. **NPDL 深度學習前後測檢核表系統**：UX 極致優化版滑桿表單，前後測 6C 素養數據一鍵圖表化。

### 🎨 四、策展展演專案
11. **2026 數實祭總舖師上菜-數位辦桌趣**：深刻體認「學會轉彎」，以純前端 Canvas 拼貼取代昂貴 API，逾 2,000 人共創無伺服器負擔。

### 🔮 五、生活、學習與身心靈跨域專案
12. **出國自由行協作即時記帳與分帳平台**：多人多幣別即時換算，演算法自動計算最少次數還款清單。
13. **人類圖 AI 深度解讀器**：導入圖片截圖辨識技術，自動生成結構化、具同理心的長篇解析。
14. **紫微斗數深度解讀器**：破除傳統宿命論，轉化為現代中學生探索性格優勢與生涯潛能的媒介。
15. **易經六十四卦自主學習決策平臺**：結合傳統智慧與現代專案管理，在面臨學習瓶頸時提供行動反思。
16. **未來 N 種待開啟的 AI 專案探索庫**：隨時開啟屬於南投國中每位老師的第 17 個專案實驗！
