## 🔐 系統存取安全控制說明

- 為保護研習教材與教學教具資源，`index.html` 設有前端授權防護門禁。
- **安全防護機制**：採用 **SHA-256 單向密碼雜湊比對驗證**，前端原始碼與 GitHub 倉庫中絕不保存或洩漏明文密碼，有效防止網路爬蟲掃描與未授權檢索。
- **操作說明**：請於首頁授權彈窗中輸入主辦單位提供之專屬通行驗證碼，系統即時計算雜湊校驗成功後自動解鎖，並自動記憶於目前瀏覽器工作階段中。
